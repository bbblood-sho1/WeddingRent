# WeddingRent

## Описание проекта

WeddingRent — защищённая информационная система
для автоматизации деятельности салона проката
свадебных нарядов.

## Основные возможности

- Просмотр каталога свадебных нарядов.
- Запись клиентов на примерку.
- Оформление проката.
- Учёт залогов.
- Регистрация дефектов нарядов.
- Управление пользователями и ролями.

## Информационная безопасность

- Аутентификация и авторизация пользователей.
- Разграничение прав доступа.
- Контроль целостности данных о залогах.
- Шифрование конфиденциальных данных.
- Журналирование действий пользователей.

## Технологии

- Python
- Flask
- PostgreSQL
- Flask-SQLAlchemy
